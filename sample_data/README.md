# sample_data

仅放合成订单、库存、供应商与采购规则样本。

`stage1.json`：2 个供应商、2 个库存物料、3 个报价、2 个订单、2 条订单物料行，共 11 条记录。
`PO-2026-10086` 的电机需求 100，可用库存 22，缺口 78，预计延期；
`PO-2026-10087` 的螺栓库存充足且按期交付。日期为固定快照，不根据当天日期更新。

用 `python -m app.seed --confirm` 显式导入配置的本地演示数据库，详细命令见根目录 README。
重复 seed 仅补充缺失记录，不覆盖修改、不删除已有数据；不预创建采购草稿。

Stage 2 的 `policies/` 包含采购管理制度、紧急采购 SOP、供应商准入与报价规则三份 Markdown 合成快照。
使用 `python -m app.import_knowledge --confirm` 显式构建本地检索索引，具体环境命令见根目录 README。
这些条款不是任何真实企业的制度，不用于实际经营或权限决策。
