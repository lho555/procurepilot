# 数据与许可

`sample_data/stage1.json` 和 `sample_data/policies/*.md` 是本地演示合成样例；制度条款不来自真实客户，也不能作为真实经营或审批依据。公开评测来自这些样例，未复用历史 python 仓库的 CSV 或 pickle。

依赖使用原有锁定清单，由各上游许可证约束；不将依赖包、虚拟环境、node_modules、数据库或浏览器 profile 打包发布。发布材料保留官方技术名与现有上游参考链接，不移除源码中的归属说明。

发布者已确认本次候选中的源码、合成样例及纳入片段可公开。本次沿用不添加统一 LICENSE 的选择，不声明 MIT 或其他统一授权；没有许可证不表示可自由再分发。

`docs/evidence/` 仅含精选合成报告、任务结果、截图和源码哈希。报告路径已改为仓库相对路径；原始本机日志、环境配置、绝对路径、数据库和完整 `.local` 不纳入公开内容。
