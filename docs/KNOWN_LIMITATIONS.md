# 工程取舍与已知限制

- 先验证采购异常的查询 → 引用 → 人工审批 → 独立执行确认闭环，采用模块化单体和合成数据，避免额外部署组件。
- 默认离线适配器组织查询事实和制度摘录；可显式启用兼容 Chat Completions 的结构化依据选择，输出受事实目录、引用编号和建议代码约束。七节点工具顺序固定，没有自主规划或模型选工具；真实服务兼容性和模型质量尚未实测，详见 [模型分析边界](MODEL_ANALYSIS.md)。
- TF-IDF 是词面基线，未使用语义 embedding / rerank；无依据时保留弃答，不保证制度一定没有相关规则。引用对应导入快照，文件变化不会自动重建索引。
- Agent MCP 客户端仅允许三个读取工具；Server 另外提供经严格确认的草稿工具，但不在 Agent 白名单中。本机 stdio 没有远程认证。
- 审批 actor 是人工标签，确认字段不能证明身份；无登录、审批人身份隔离、多租户或生产角色权限。仅适合可信本机合成演示。
- 幂等范围是 `/workflows` 创建及已提交本地状态恢复。直接草稿 API / MCP 创建没有幂等键，重复确认可能创建多份；不要自动重试写入，提交后响应丢失先核对原记录。
- checkpoint 是应用层业务阶段快照，不是 LangGraph 原生 saver / interrupt。分析提交前崩溃可能重做整段只读分析；恢复不会自动刷新库存或制度，硬崩溃可能需等待 60 秒租约后人工恢复，没有常驻自动恢复 worker。
- 事务失败回滚；本地回执与完成 checkpoint 同事务。没有真实采购、支付、扣库存、外部补偿或跨系统 exactly-once 保证。
- 独立分析和导入报告仅保留在页面内存，刷新后需重新分析 / 导入；持久工作流可从库中查询。UI 仅做报告格式检查与展示，不认证真实性。
- 固定合成任务分数只覆盖观测范围，不能推断模型准确率、全部安全故障、生产性能或客户收益。
- 前端构建存在主 chunk 体积警告；未因求职展示进行无业务需求的依赖升级或拆分。
- 本次验收复用已有依赖，仅测 Windows / SQLite；全新依赖下载、其他平台、最低版本矩阵、MySQL、生产部署及 15 分钟启动均未复验。
