# 模型响应验收

本入口离线回放模型响应，复用应用中的 Chat Completions 适配器，验证响应契约与固定合成题集标注。它不会读取模型配置或凭据，不连接模型服务，不创建采购草稿，不产生模型调用费用。

题集包含 12 个案例：缺货并延期、仅缺货、仅延期、无异常，以及缺少制度、虚构事实、错误引用、越权建议、截断、拒答、超时和服务错误。前四个案例有固定的引用适用性与建议覆盖标注，后八个案例检查拒绝或超时处理。题集是本项目的合成验收标准，不代表真实业务制度已经专家审核。

## 运行与展示

```powershell
./.venv/Scripts/python.exe scripts/run_model_evals.py --confirm
```

`--confirm` 只允许创建 `.local/model-evals/<唯一ID>/report.json` 和 `report.md`，没有该参数时命令拒绝写入。内置响应回放全部通过返回 0，任一案例失败返回 1，输入错误或缺少确认返回 2。它同样包含在统一入口 `scripts/verify_delivery.py --confirm` 中。

打开工作台“模型验收”页，选择生成的 JSON。文件仅在浏览器内读取，页面不上传或运行模型；清除或刷新后需重新导入。页面检查每个案例、指标分子分母及整体结果是否一致，拒绝包含在线请求或真实模型质量声明的报告。格式核验不能认证报告来源，也不能证明文件没有被整体重写。

## 导入记录的响应

可按 `evals/model_responses.json` 的格式准备本地记录，再运行：

```powershell
./.venv/Scripts/python.exe scripts/run_model_evals.py --confirm --responses .local/recorded-responses.json
```

输入文件须包含 `version=1`、当前 `evals/model_cases.json` 的文件 SHA256，以及完整且不重复的案例 ID。两份内置 JSON 通过 `.gitattributes` 固定为 LF，避免检出换行转换造成摘要错配。每条响应为一种事件：

- `completion`：在 `response` 中放入完整的 Chat Completions JSON。
- `timeout`：回放超时，不携带响应体或状态码。
- `http_error`：提供 400～599 的 `status`，不携带响应体。

题集与响应文件均限制为 2 MB，案例数限制为 30。不能只提供成功案例或用其他版本题集的响应获得完整成绩。输入错误在创建报告目录之前拒绝，不在错误信息中回显文件内容。

有 `--responses` 时报告标记 `recorded_replay`，默认标记 `fixture_replay`；两者都只使用本地 HTTP 响应替身。导入记录可用于核对手工采集的合成数据响应，但本入口不证明它来自哪个真实服务，也不观察记录采集时的真实时延、费用或超时发生过程。真实服务采集仍需事先确认提供方、具体模型、合成数据范围与费用上限。

## 指标含义

| 指标 | 适用案例 | 判定 |
| --- | --- | --- |
| 案例验收 | 全部 | 结果、单次请求约束及适用检查全部通过 |
| 事实约束 | 预期采纳 | 实际适配器通过严格事实与输出校验 |
| 引用符合题集标注 | 预期采纳 | 所选引用均属于该案例标注的适用引用 |
| 建议覆盖题集要求 | 预期采纳 | 包含标注的所有必要建议 |
| 预期失败处理 | 预期拒绝或超时 | 实际结果与预期一致 |
| 预期失败却被采纳 | 预期拒绝或超时 | 被采纳计为违规，比例越低越好 |

适用失败始终保留在分母中，不适用项用 `null` 排除。编号存在但内容不适用的引用，可能通过应用契约，却会在题集评分中失败；安全但遗漏关键建议的回答也不会拿满分。

报告记录题集和输入响应的 SHA256，输出编号、允许的建议代码及检查结果，不保存原始响应、模型自由文本、原始错误或输入文件路径。`local_validation_ms` 是本地回放耗时，`provider_attempts` 是响应替身触发次数，不代表实际调用了在线服务。`live_model_requests=0`；模型时延与模型费用均为 `null`（未测量），不能将其解释为采集原始响应免费或模型实时响应很快。

## 保留边界

此评分工具不提供线上计费限制、来源认证、真实采购权限或模型质量认证。它不改变默认离线模式、固定工具顺序、事实计算和人工审批边界。真实模型验收与更多案例的人工标注仍是 Stage 9 后续工作；配置边界见 [MODEL_ANALYSIS](MODEL_ANALYSIS.md)。
